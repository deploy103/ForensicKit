# .agent/PROJECT_CONTEXT.md

이 파일은 보조 컨텍스트다.

가장 중요한 규칙은 루트의 `AGENTS.md`와 `요구사항.md`다.

개발 에이전트는:
- 사소한 선택 때문에 작업을 멈추지 않는다.
- 합리적인 기본값을 선택한다.
- 구현 후 테스트를 직접 실행한다.
- 실패하면 원인을 조사하고 수정한 뒤 다시 테스트한다.
- 단순 placeholder/mock으로 완료 처리하지 않는다.
- 실제 외부 포렌식 툴을 탐지하고 가능한 경우 실제 명령으로 smoke test한다.
- 인터넷이 끊긴 runtime을 최종 기준으로 삼는다.
