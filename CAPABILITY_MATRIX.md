# ForensicKit Capability Matrix

| Area | Identification | Native bounded parsing | Extraction / correlation | External verification |
| --- | --- | --- | --- | --- |
| Generic / flags | Yes | Hash, strings, entropy, signatures, transforms | Recursive archives | file, ExifTool, binwalk, YARA when available |
| Image / stego | Yes | PNG/JPEG/GIF/TIFF/BMP structure; JPEG APP/EXIF/XMP/ICC/Photoshop metadata | Appended/container recursion; XMP FlagHunter offset provenance | pngcheck, zsteg, steghide, binwalk |
| Archive | Yes | ZIP/TAR/gzip/bzip2/xz checks | Bounded child registration | 7z, carving tools |
| PCAP | Yes | PCAP/PCAPNG, TCP/HTTP/DNS/TLS ClientHello, ServerHello, and Certificate metadata with bounded continuation checks; TLS 1.2/1.3 certificate fingerprint inventory; HTTP gzip/deflate and multipart Base64/quoted-printable response-part decoding; RFC 5987/2231 filenames; PASV/EPSV/PORT/EPRT FTP RETR/STOR and AUTH TLS transitions; SMTP DATA/BDAT MIME attachments; POP3 RETR/MIME attachments and STLS transitions; IMAP FETCH/MIME attachments and STARTTLS transitions; bounded SMB2 NEGOTIATE/TREE_CONNECT/CREATE/FileId, acknowledged WRITE/READ payloads, CLOSE lifecycle metadata/size validation, SET_INFO rename/delete intent, QUERY_DIRECTORY FileNames/FileIdBoth metadata, and opaque SMB3 transform headers; TXT Base64 reconstruction | HTTP object/multipart-part, FTP transfer/listing, SMTP DATA/BDAT message/attachment, POP3 RETR message/MIME-attachment, IMAP FETCH message/MIME-attachment, and SMB2 WRITE/READ/directory-listing recursion with bounded control/data provenance; endpoint/packet TXT, SMB2/3 dialect/signing/capability/share/filename/FileId/status/lifecycle/mutation/directory/transform metadata, inverse-flow TLS negotiation, mail/FTP encryption-transition, ALPN mismatch, and certificate packet provenance | tshark, capinfos |
| Windows Registry | Yes | Base block, HBIN, bounded NK/VK persistence allowlist | Exact supplied `.LOG1`/`.LOG2` provenance | RegRipper |
| Windows artifacts | Yes | EVTX header/chunks/record framing, Registry, LNK/Prefetch metadata, lineage-gated `$UsnJrnl:$J` V2/V3/V4 records and exact adjacent V2 rename pairing | Exact V2 USN→ancestor sampled-MFT correlation; EVTX/USN timeline including V4 ranges; EVTX↔memory/LNK/Prefetch and Registry persistence-command correlations | Hayabusa, Chainsaw, RegRipper |
| Memory | Yes | Minidump streams including modules, threads, ranges, handles, unloaded modules | PsList/PsScan, PID-scoped DLL/handle path correlation, file-scan and bounded dumpfiles child recursion | Volatility 3 |
| Mobile | Yes | Android backup/APK; iOS plist/Manifest.db | Exact supplied iOS payload correlation and bounded domain/path semantic leads (1,000 references; no BLOB decoding) | ALEAPP, iLEAPP |
| Disk/filesystem | Yes | Partition headers; exFAT dual boot/root/subdirectories; FAT32 root/subdirectories; bounded ext2/3 direct and ext4 depth-zero/depth-one-extent active directory/inode tree; NTFS boot/`$MFTMirr`/MFT/`$I30` | exFAT/FAT32 deleted-file recursion; active ext root/subdirectory file recursion; sampled NTFS recovery/correlation | SleuthKit/EWF |
| TUI / reporting | Yes | Read-only case database loading and bounded raw-output preview | Keyboard case tables and JSON/Markdown reports; deduplicated CSV timeline retains EVTX/USN artifact, native offset, observation/tool-run/raw-output, cluster, and correlated sampled-MFT provenance | Headlessly validated with Textual 8.2.8 |

`Yes` means offline runtime support; external tools remain optional and missing tools are recorded instead of fatal.
